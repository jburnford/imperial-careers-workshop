# Saved output for step 1 of the delegation: proposed record structures

Two proposals in answer to the same prompt (see `../02-extract/README.md`). Both chose one flat table with typed local identifiers, verbatim quotes with line references, and separate fields for inferred material and for outside identification. They differ in granularity: run A has 22 fields and separate action rows with subject, verb and object; run B has 15 fields and lists variant printed forms on each record.

Neither is the right answer. The point of showing two example records before processing the rest is that the historian chooses what a record is before the model makes hundreds of them.
