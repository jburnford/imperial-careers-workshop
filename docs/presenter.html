The consequential problem to find together

The editor’s bracketed note above Agar’s letter says that Howard “analyzed the bark” of the tree Trimen figured. Agar’s letter says that bark from some of these trees went to Howard, and that the bark from the tree itself is in Agar’s own possession. A model that follows the editor conflates the two. Neither rehearsal run did: run A recorded the editor’s claim as the editor’s and noted that which trees supplied the bark “is not stated beyond ‘some of these trees’”; run B noted on the editor’s affirmation that Agar only says the figured tree was “one of several”. Show run A’s bark record and ask the room whether they would have caught it if the model had not. If a live run in the room does conflate them, better still.

Then the OCR check: both runs flagged the two damaged sentences and guessed at the wording (run A “in full bloom”; both runs “by me”). The scan says “growing in a bad situation and not robust” and “many plants from the seed of the specimen tree”. The models were right to flag and wrong to guess.

Online participation

  • Remote participants see the same pages and the same exercise. Nothing requires a login.
  • The exercise page’s Copy summary button produces one line (R1 accept; R2 reject; ...) for pasting into the Zoom chat, so the chat monitor can read decisions out.
  • Participants can Download TSV of their decisions with reasons. If the organizers want them collected, say where to send the file.
  • Recording is the conference’s arrangement. The materials stay online afterwards.

What not to claim

  • The research pipeline’s links for Trimen are automated. Say so.
  • The handpicked cases are failure modes, not an accuracy rate.
  • The RA’s evaluation of Tropical is pending. The workshop uses a separate frozen packet and does not touch it.
